ADAPTATION AND WRITTEN APPROVAL
The project maintainer has obtained written approval from
Ruminastro to try adapting the game into a web-based client. This notice
records that permission as reported by the maintainer; the correspondence
itself has not been supplied with this project or reproduced here. No
additional permission terms, approval date, or endorsement are asserted.

This unofficial adaptation adds a browser interface, automated UUID and
rules handling, a formatted scratchpad, local saves, and a terminal-style
presentation. Implementation interpretations are documented in README.md.
The original game wording is unchanged. The text extraction whitespace has
been restored from the PDF; the previous extraction is retained in
reference/original-extraction.txt. The original PDF is unchanged.
